# 用 React + wagmi + viem + Material-UI 实现 RainbowKit ConnectButton（自定义钱包连接组件）详细中文实战教程

本教程手把手教你如何不用 RainbowKit 的 ConnectButton，但实现相同钱包连接功能。将分功能点详解代码实现，每部分包含理由/注释和 TypeScript 代码片段，适合新手和教学。

## 一、准备知识

### 涉及技术栈

- **React** 前端主框架
- **TypeScript** 强类型脚本
- **wagmi** 钱包连接、账户管理核心库
- **viem** 一个快速且轻量级的以太坊客户端（常配合 wagmi 使用）
- **@mui/material** Material-UI 组件库，用于美化界面

### 涉及钱包

本例支持：
- MetaMask
- OKX Wallet
- Phantom
- Coinbase Wallet

**注意：Phantom 主要支持 Solana 但也新近支持 EVM，请根据用户浏览器环境注入检查。**

## 二、ConnectButton 应该有的基本功能清单

1. 列出可用钱包类型并显示连接按钮
2. 连接钱包（发起连接，监听回应）
3. 显示已连接钱包信息（如地址、网络、头像等）
4. 支持断开连接（登出）
5. 错误处理（缺插件、拒绝连接等提示）
6. 处理钱包切换事件（如账户切换、网络切换）

### 2. 设置 wagmi：配置 chains 和 connectors

你要初始化支持的钱包（MetaMask, OKX, Phantom, Coinbase），wagmi 使用 connector 对接浏览器钱包。

#### 2.1 创建 wagmiConfig.ts

```typescript name=src/wagmiConfig.ts
import { configureChains, createConfig } from 'wagmi'
import { mainnet } from 'wagmi/chains'
import { publicProvider } from 'wagmi/providers/public'

import { MetaMaskConnector } from 'wagmi/connectors/metaMask'
import { OkxWalletConnector } from '@okwallet/wagmi-connector' // 需查找此包或使用 InjectedConnector
import { CoinbaseWalletConnector } from 'wagmi/connectors/coinbaseWallet'
import { InjectedConnector } from 'wagmi/connectors/injected'

export const { chains, publicClient } = configureChains(
  [mainnet], // 可加其他链
  [publicProvider()]
)

// Phantom 支持以太坊（需用通用InjectedConnector检测 window.ethereum.isPhantom）
function phantomConnector() {
  return new InjectedConnector({
    chains,
    options: {
      name: 'Phantom',
      getProvider: () =>
        typeof window !== 'undefined' && (window as any).ethereum?.isPhantom
          ? (window as any).ethereum
          : undefined,
    },
  })
}

// OKX Wallet也一般通过检测 window.okxwallet 或 window.ethereum.isOkxWallet，或用 InjectedConnector
function okxConnector() {
  return new InjectedConnector({
    chains,
    options: {
      name: 'OKX Wallet',
      getProvider: () =>
        typeof window !== 'undefined' && (window as any).okxwallet
          ? (window as any).okxwallet
          : undefined,
    },
  })
}

export const connectors = [
  new MetaMaskConnector({ chains }),
  okxConnector(),
  phantomConnector(),
  new CoinbaseWalletConnector({
    chains,
    options: {
      appName: 'My App',
    },
  })
]

export const wagmiConfig = createConfig({
  autoConnect: true,
  connectors,
  publicClient
})
```
**解释：**
- 每个钱包有各自连接器。MetaMask、Coinbase Wallet有官方connector，OKX Wallet和Phantom没有官方的，需要用`InjectedConnector`和检测window对象自定义。
- `autoConnect` 方便刷新页面时自动重连。

### 3. App 启动 wagmiProvider

根组件引入 wagmiProvider 让配置生效。

```typescript name=src/main.tsx
import React from 'react'
import ReactDOM from 'react-dom'
import App from './App'
import { WagmiConfig } from 'wagmi'
import { wagmiConfig } from './wagmiConfig'

ReactDOM.render(
  <React.StrictMode>
    <WagmiConfig config={wagmiConfig}>
      <App />
    </WagmiConfig>
  </React.StrictMode>,
  document.getElementById('root')
)
```

### 4. 实现 ConnectButton 组件

#### 4.1 设计 UI与状态

使用Material UI的`Button`和`Menu`。用 React 的 useState 管理弹窗，判断连接状态，显示钱包种类，已连接时显示地址与断开按钮。

```typescript name=src/components/ConnectButton.tsx
import React, { useState } from 'react'
import Button from '@mui/material/Button'
import Menu from '@mui/material/Menu'
import MenuItem from '@mui/material/MenuItem'
import Avatar from '@mui/material/Avatar'
import { useAccount, useConnect, useDisconnect } from 'wagmi'
import type { Connector } from 'wagmi'

const WALLET_ICONS: Record<string, string> = {
  'MetaMask': 'https://raw.githubusercontent.com/MetaMask/brand-resources/master/SVG/metamask-fox.svg',
  'OKX Wallet': 'https://static.okx.com/cdn/wallet/logo_OKXWallet_light.svg',
  'Phantom': 'https://www.phantom.app/img/logo.png',
  'Coinbase Wallet': 'https://avatars.githubusercontent.com/u/18060234?s=200&v=4'
}
// 上述为钱包logo，按个人需求整理链接即可

export default function ConnectButton() {
  // wagmi hooks
  const { address, isConnected, connector } = useAccount()
  const { connect, connectors, isLoading, pendingConnector, error } = useConnect()
  const { disconnect } = useDisconnect()
  // UI状态 hook
  const [anchorEl, setAnchorEl] = useState<null | HTMLElement>(null)

  const handleClick = (event: React.MouseEvent<HTMLButtonElement>) => {
    setAnchorEl(event.currentTarget)
  }
  const handleClose = () => {
    setAnchorEl(null)
  }

  // 钱包logo
  const currentWallet = connectors.find(
    (c) => c.id === connector?.id
  )
  const currentWalletIcon = currentWallet ? WALLET_ICONS[currentWallet.name] : undefined

  if (isConnected && address) {
    // 已连接显示账户、头像等，附断开按钮
    return (
      <Button
        variant="contained"
        color="success"
        onClick={handleClick}
        startIcon={currentWalletIcon ? <Avatar src={currentWalletIcon} sx={{ width: 24, height: 24 }} /> : null}
      >
        {address.slice(0, 6)}...{address.slice(-4)}
        <Menu open={Boolean(anchorEl)} onClose={handleClose} anchorEl={anchorEl}>
          <MenuItem disabled>{connector?.name}</MenuItem>
          <MenuItem onClick={() => { disconnect(); handleClose() }}>断开连接</MenuItem>
        </Menu>
      </Button>
    )
  }

  // 未连接钱包
  return (
    <>
      <Button
        variant="contained"
        color="primary"
        onClick={handleClick}
      >
        连接钱包
      </Button>
      <Menu open={Boolean(anchorEl)} onClose={handleClose} anchorEl={anchorEl}>
        {connectors.map((wallet) => (
          <MenuItem
            key={wallet.id}
            disabled={!wallet.ready}
            onClick={() => {
              connect({ connector: wallet as Connector })
              handleClose()
            }}
          >
            {WALLET_ICONS[wallet.name] &&
              <Avatar src={WALLET_ICONS[wallet.name]} sx={{ width: 24, height: 24, mr: 1 }} />
            }
            {wallet.name}
            {!wallet.ready && '（未检测到插件）'}
            {isLoading && pendingConnector?.id === wallet.id && '（连接中）'}
          </MenuItem>
        ))}
      </Menu>
      {error && <div style={{ color: 'red', padding: 8 }}>错误：{error.message}</div>}
    </>
  )
}
```

**注释说明：**
- 利用`useConnect`/`useAccount`自动管理连接钱包与当前账户。
- `Menu`弹窗展示可用钱包，自动 disabled 未装插件的 option。
- 已连接状态显示钱包logo与地址，以及断开按键。
- 如果连接失败/用户拒绝，会显示错误信息。
- 钱包的头像通过预设的URL映射给`Avatar`。
- `.slice(0, 6)`和`.slice(-4)`用来缩略显示地址。

## 六、常见问题与扩展思路

- 钱包插件检测依赖浏览器 window 对象；部分钱包如 Phantom/OKX 需装好插件后再用。
- 断开连接后会清理 wagmi/viem 管理的本地钱包状态。
- 若需网络切换/手动加链/显示多链，需进一步用 wagmi 的 `useNetwork` 和 `switchNetwork`。
- 头像/ENS 可以用 wagmi 的 `useEnsAvatar/useEnsName`。
